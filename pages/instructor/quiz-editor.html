1-modul yakuniy testi

8 savol · ~15 daq

1-modulni yakunlagach bilimni tekshirish uchun test. Har bir savolga diqqat bilan javob bering. Vaqt tugagach test avtomatik yakunlanadi.

O'tish balli
70%

Savollar tartibi

  1. Python'da qaysi kalit so'z funksiya e'lon qiladi? Bitta tanlov
  2. Quyidagilardan qaysilari o'zgaruvchan (mutable) turlar? Ko'p tanlov
  3. Python interpretatsiya qilinadigan til hisoblanadi To'g'ri/Noto'g'ri
  4. print() funksiyasi nima uchun ishlatiladi? Qisqa javob
  5. Docker konteynerining afzalliklarini tushuntiring Batafsil javob
  6. Har bir Git buyrug'ini tavsifiga moslashtiring Moslashtirish
  7. Docker image yaratish bosqichlarini to'g'ri tartibda joylashtiring Tartiblash
  8. Python'da ro'yxat elementiga ___ orqali murojaat qilinadi Bo'sh joyni to'ldirish

Bu talaba ko'radigan test sahifasining taxminiy ko'rinishi — faqat oldindan ko'rish rejimi.
